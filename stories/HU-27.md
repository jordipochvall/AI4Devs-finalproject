# HU-27 — El operador consulta el detalle de una partida desde la auditoría

> **Como** operador,
> **quiero** abrir el detalle de una partida concreta desde la pantalla de auditoría (importes, símbolos resultantes y líneas ganadoras) sin lanzar el replay completo,
> **para** resolver una reclamación de un vistazo, de forma más ligera y rápida que la reproducción visual.

**Contexto y valor.** El endpoint `GET /operator/rounds/{roundId}` se especificó y construyó en **[HU-16](HU-16.md)** (detalle de partida del operador), pero la **UI nunca lo consumió**: la auditoría sólo ofrecía el *replay*. Esta historia cierra ese hueco —detectado al cruzar el catálogo de endpoints del [`readme.md`](../readme.md) §4 con las llamadas reales del frontend— añadiendo un **modal de detalle ligero** en la pantalla de auditoría, manteniendo el replay para la reproducción visual completa. No requiere backend nuevo (reutiliza el endpoint existente).

**Prioridad:** Could Have · **Estimación:** S · **Endpoint:** `GET /operator/rounds/{roundId}` *(ya implementado en `HU-16-BE-01`)*

## Criterios de aceptación (BDD)

```gherkin
# language: es
Característica: Detalle de una partida en la auditoría del operador

  Antecedentes:
    Dado un operador autenticado en la pantalla de auditoría con partidas listadas

  Escenario: Abrir el detalle de una partida
    Cuando pulso "Detalle" en la fila de una partida
    Entonces se abre un modal con sus importes (apuesta, premio, saldo antes/después),
            la rejilla de símbolos resultante y las líneas ganadoras
    Y no se carga la configuración ni se reproduce el giro (es más ligero que el replay)

  Escenario: Cerrar el detalle
    Cuando cierro el modal (botón, fondo o tecla Escape)
    Entonces vuelvo a la lista de auditoría sin perder mis filtros

  Escenario: El replay sigue disponible
    Cuando pulso "Replay" en la misma fila
    Entonces accedo a la reproducción visual completa (sin cambios respecto a HU-3)

  Escenario: Aislamiento por operador
    Cuando solicito el detalle de una partida que no pertenece a mi operador
    Entonces el servidor responde 404 y la UI muestra un mensaje de error
```

## Verificación INVEST

| Criterio | Cumplimiento |
|---|---|
| **I**ndependiente | Sólo añade superficie de frontend sobre un endpoint que ya existe (HU-16). |
| **N**egociable | El conjunto de campos del modal y su disposición son negociables. |
| **V**aliosa | Cierra el único endpoint del §4 sin consumidor de UI; agiliza el soporte de reclamaciones. |
| **E**stimable | Un *hook* de consulta + un modal accesible + i18n + tests. |
| **S**mall | Reutiliza el endpoint, los tipos (`WinningPayline`/`view`) y el patrón de modal existentes. |
| **T**estable | Verificable renderizando el modal con un detalle conocido y comprobando importes, rejilla y líneas. |

**Fuera de alcance:** cualquier cambio de backend (el endpoint ya existe), y la reproducción animada (sigue siendo el *replay* de HU-3).
